# LUMIÈRE · 智能 3D-AR 拟真试衣镜系统

> **面向高端商场与品牌专柜的下一代数字化试衣交互大屏终端**  
> 融合高定剪裁工艺、3D-AR 物理布料仿真与严格的线下隐私合规保护，为顾客提供无需脱衣、真实体态 1:1 精准贴合的沉浸式试衣体验。

---

## ✦ 设计理念与美学风格

本项目采用 **Apple 奢品极简美学（Apple Luxury Minimalist Design）** 打造：
- **纯净暖白底色**：以温润沉静的米白纸质基调（`#F8F7F4`）与卡片纯白（`#FFFFFF`）构建高雅空间感，契合高端商场光影环境。
- **高精极细黑线**：摒弃笨重粗黑线条，全界面采用克制、精密的 `border-stone-900/10` 与选定态 `border-stone-950`，线条干净利落。
- **经典胶囊交互**：采用苹果经典的纯黑圆角胶囊主操作键（Pill Buttons）、分段指示器（Segmented Pill Controls）与极简轮廓辅键。

## ✦ 核心 4 步试衣全流程

```
[第 1 步] 形象与隐私 ──▶ [第 2 步] 挑选服装 ──▶ [第 3 步] 智能计算 ──▶ [第 4 步] 试穿呈现与扫码
```

### 1. 形象采集与隐私保护 (Avatar & Privacy Setup)
- **多模式形象输入**：
  - **实拍照试穿（推荐）**：支持顾客现场摄像头高清自拍实测或本地手机照片上传。
  - **内置标准实拍照**：提供免拍摄的现场试衣镜标准实拍模板。
  - **高定模特身型库**：针对男女士提供多样化体态（如高挑修身、标准沙漏型、微丰满型）供快速选型。
- **三重隐私遮蔽方案**：
  - **清晰自然**：原貌保留，五官发型神态最自然。
  - **面部柔化模糊**：自动定位并虚化面部区域，有效保护顾客肖像隐私。
  - **高定黑超墨镜**：智能眼部佩戴轻奢墨镜遮挡，时尚美观与护隐兼备。

### 2. 服饰自由选搭 (Apparel Curation)
- **多品类精选**：覆盖外套大衣、真丝衬衫、高定西裤、优雅礼裙等多品类单品。
- **多件自由叠穿**：支持单品试穿，亦支持外套 + 内搭 + 裤装的多件叠穿组合。
- **一键穿搭全套造型**：为顾客快速一键配置当季推荐 Lookbook 套装。

### 3. 智能物理对齐解剖运算 (Wait & Physics Simulation)
- **解剖学锚点智能识别**：自动锁骨中窝、左右肩峰点、腰节线及腿部双轴线。
- **真实悬垂仿真**：模拟重磅真丝、精纺羊毛与皮革的自然悬垂感与重力褶皱。
- **流畅动效反馈**：极简呼吸光环与进度反馈，支持随时快速呈现。

### 4. 3D-AR 试穿效果呈现与对比 (Interactive Try-On Canvas)
- **左右滑动交互比对（Before / After）**：拖动中央金线滑块，实时无缝对比原始着装与试穿新衣的立体效果。
- **衣服精准对齐双肩，裤装精确对齐双腿**：杜绝贴纸感，衣物按体态骨骼自然包裹。
- **高定剪裁版型切换**：支持「标准合身」、「修身收腰」与「自然微廓」不同廓形自适应。
- **光影与透视辅助**：支持环境光融合切换、人体解剖骨骼锚线透视与面料张力热力透视。
- **微信扫码端对端带走**：顾客使用手机扫描极简二维码即可带走试穿海报，避免大屏残留。

## ✦ 线下大屏隐私安全与数据合规保障

严格遵从《个人信息保护法》与线下商用安全合规规范：

| 安全特性 | 实现机制 |
| :--- | :--- |
| **边缘沙盒算力** | 采用本地纯边缘计算，所有运算在单机显存与沙盒中执行，**绝不回传云端**。 |
| **不建立人脸库** | 仅识别人体几何骨架拓扑，**绝对不沉淀、不比对、不留存任何人脸生物识别信息**。 |
| **30 秒离屏自动清空** | 顾客离屏超时 30 秒无人操作，系统自动触发安全复位，物理级清空照片与体态数据。 |
| **一键即刻物理销毁** | 顶栏与安全弹窗均常设「重置」与「立即一键物理销毁」，可随时彻底抹除个人数据。 |

## ✦ 技术架构与实现

- **前端核心**：React 18 + TypeScript
- **构建工具**：Vite
- **样式工程**：Tailwind CSS（基于 `@import "tailwindcss";` 与苹果极简主题变量）
- **图标系统**：Lucide React
- **动效库**：Motion / CSS Keyframes
- **渲染画布**：HTML5 Canvas / CSS Clip-path 双层高保真图像混合渲染器

## ✦ 快速本地运行

### 环境要求
- Node.js 18+
- npm 或 pnpm / yarn

### 安装并启动
```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务（默认监听端口 3000）
npm run dev
```

在浏览器打开 `http://localhost:3000` 即可体验大屏试衣镜系统。

### 生产环境打包
```bash
npm run build
```
打包输出将保存在 `dist/` 目录中。
